自訂興趣／維度標籤

手動匯入 · 體重／睡眠／經期／運動

網頁與微信小程序均無法直接連接 Apple Health（HealthKit）。請用手動入帳、對話一句話、或 CSV／JSON 匯入。微信端步數可用「微信運動」授權同步近約 30 日。

建議流程
1）下載 IMPORT_TEMPLATE.csv 範本，填入體重／睡眠／經期／運動（或步數）
2）下方「匯入 CSV／範本」合併入帳；亦可匯入 BloomBody 備份 JSON 或 Health-shaped 互換檔
3）若從 iPhone「健康」匯出 ZIP／XML，請自行在試算表對齊到範本欄位後再匯入（見 IMPORT_APPLE備註.md）
下載匯入範本 CSV

互換檔為 BloomBody 自訂格式，並非 Apple／Google 官方 dump；本產品不宣稱已連接 HealthKit。

SPA ↔ 微信雲同步 可選

填寫上方「雲端 AI」同一 API Base URL（或獨立同步網關）。同一顯示名帳號可與微信小程序共用 users／records。未設定 Base／離線時全部寫本機；上線後可手動拉取／推送。

修改密碼

匯出資料

CSV 可直接用 Excel／Google Sheet 打開。JSON 用作完整備份還原。

匯入備份／CSV 範本

匯入會合併記錄（相同 recordId 會覆蓋；微信運動／步數按日期更新）。建議先匯出備份。此為手動匯入，非連接 Apple 健康。

常用清單

刪除我的資料同相片

僅刪除目前登入用戶的記錄及對應 IndexedDB 圖片；其他用戶資料保留。無法復原。

管理員

清除後無法復原（除非你有 JSON 備份）。會連 IndexedDB 相片一併清。

重要免責
1. 所有飲食熱量、消耗熱量僅為估算，並非精準醫學數據。
2. 本應用僅為記錄工具，並非醫生診斷；有疾病（膽囊結石、子宮肌瘤、血脂偏高、膝蓋問題）請遵從醫生指示。
3. 預設資料儲存於瀏覽器本地；設定 API Base 並啟用雲同步後，同一帳號可與微信小程序共用記錄。離線或未設定時自動退回本機，建議仍定期匯出 CSV／JSON 備份。
4. 「私密」標籤僅為應用內部顯示控制，並非加密保安，請勿存放極敏感醫療資料。
